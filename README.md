## About ByteSweep

ByteSweep builds software that helps people understand what is using their storage, decide what to remove, and keep their devices organised.

The product family spans desktop, mobile, and command-line tools. Each application is designed for its platform, with an emphasis on visibility, deliberate actions, and keeping users in control of their files.

## What we focus on

| Area | What ByteSweep helps with |
|---|---|
| **Storage visibility** | Understand which files, folders, caches, and system data use storage. |
| **Careful cleanup** | Review cleanup candidates and choose what to remove. |
| **File organisation** | Find duplicates, large files, old downloads, and files that need attention. |
| **System utilities** | Monitor system activity and review maintenance-related information. |
| **Developer workflows** | Identify storage used by tools, build data, package caches, containers, and local development environments. |
| **Device-to-device transfer** | Send files between supported computers and phones over local Wi-Fi. |
| **Terminal and server workflows** | Inspect storage and work with systems from the command line, including over SSH. |

## Designed around user control

ByteSweep is built to make storage maintenance understandable and reviewable.

- **Inspect before changing.** A scan shows information; it does not itself clean files.
- **Choose what goes.** Cleanup candidates are presented for review before removal.
- **Recover supported cleanups.** On Mac, Windows, and Linux, supported cleaned files can be restored for seven days.
- **Keep transfers local.** Device-to-device transfers use the local Wi-Fi network or a phone hotspot. Transfers are encrypted and require acceptance by the receiving device.
- **Keep personal files on the device.** ByteSweep does not require an account or upload personal files for its storage-management workflows.

Some system-level actions cannot be undone. ByteSweep identifies those actions before they are carried out.
